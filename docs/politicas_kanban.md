# Tablero Kanban: políticas por columna

| Columna | Límite WIP | Política de entrada | Política de salida |
|---|---|---|---|
| Por hacer | 5 | La tarea debe estar definida y priorizada | La tarea tiene responsable y está lista para iniciar |
| En desarrollo | 3 | La tarea tiene responsable y requisitos claros | El desarrollo está terminado y listo para pruebas |
| En revisión / pruebas | 2 | El desarrollo de la tarea está terminado | Las pruebas se ejecutan correctamente y no existen defectos críticos |
| Listo para desplegar | 2 | La tarea superó las pruebas y cumple la Definition of Done | La tarea está aprobada para despliegue |
| Hecho | Sin límite | El despliegue fue realizado correctamente | La tarea está terminada y cuenta con evidencia |
